Two ways to repaint a kitten

This project began as a notebook following A Neural Algorithm of Artistic Style (Gatys, Ecker and Bethge, 2015). It starts from the photo and adjusts the pixels over 1,000 steps, until the image-recognition network VGG-19 still sees a kitten but measures the same textures as the painting. Every new pair starts over.

The table uses a later method that the notebook also tries: Magenta’s arbitrary stylization. One network reduces any painting to 100 numbers, and a second repaints the photo from those numbers in a single pass. That is what makes it quick enough to run on your own device.
